# MorphUI Frontend

仿 Claude 桌面版布局的 React 前端（Vite + TypeScript）。

## 界面结构

```
┌──────────┬──────────────────────────────┐
│          │  顶栏：模型 / 后端状态 / 主题  │
│  历史对话 ├──────────────────┬───────────┤
│  侧栏    │                  │           │
│ (可隐藏) │    聊天对话区域    │ 实时预览   │
│          │  （消息 + 输入）   │ 区域(iframe)│
└──────────┴──────────────────┴───────────┘
```

- 左侧历史对话侧栏：搜索、按时间分组、可收起/展开
- 中部聊天区域：发送消息 → FastAPI 后端回显接口
- 右侧实时预览区域：iframe 加载任意 dev server 地址（默认指向后端演示页），支持改址 / 刷新 / 新窗口打开
- 深色 / 浅色主题切换，顶栏显示后端连接状态

## 开发

```bash
npm install
npm run dev      # http://localhost:5273
```

## 与后端的连接

- 开发期 `/api/*` 请求由 Vite 代理转发到 `http://127.0.0.1:8000`（见 `vite.config.ts`）；
- 需先启动后端仓库（morphui-backend）：`uvicorn app.main:app --port 8000`。

## 构建

```bash
npm run build    # 类型检查 + 产物输出到 dist/
```
